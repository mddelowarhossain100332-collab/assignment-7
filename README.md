# 🛒 বাজার দর (BazarDor)

প্রয়োজনীয় পণ্যের আজকের বাজার দর এক নজরে — চাল, ডাল, তেল, সবজি, মাছ, মাংস ও মসলা। পুরো ওয়েবসাইটটি বাংলায়।

## ব্যবহৃত প্রযুক্তি
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + DaisyUI
- BetterAuth (Email/Password, Google, GitHub) + PostgreSQL
- react-hot-toast

## মূল ফিচার
1. **লাইভ প্রাইস টিকার** — ইমোজি, নাম, দাম ও ▲/▼ শতাংশসহ অসীম স্ক্রলিং স্ট্রিপ
2. **আজ দাম বেড়েছে / কমেছে** — সবচেয়ে বেশি বাড়া ও কমা ৬টি করে পণ্য
3. **ক্যাটেগরি পেজ ও সর্ট** — দাম কম থেকে বেশি / বেশি থেকে কম (বাংলা সংখ্যা সঠিকভাবে সংখ্যা হিসেবে সর্ট হয়)
4. **প্রোটেক্টেড ডিটেইলস পেজ** — বিভাগ ও বাজারভিত্তিক সর্বনিম্ন, সর্বোচ্চ ও গড় দাম
5. **BetterAuth অথেন্টিকেশন** — ইমেইল/পাসওয়ার্ড ও সোশ্যাল লগইন, টোস্ট নোটিফিকেশন, প্রোফাইল আপডেট
6. স্কেলেটন লোডার, ৪০৪ পেজ, মোবাইল-ট্যাবলেট-ডেস্কটপ রেসপন্সিভ ডিজাইন
